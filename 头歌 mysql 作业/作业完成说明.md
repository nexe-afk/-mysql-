## 使用说明

1. 每个 `.sql` 文件包含对应练习的 SQL 语句
2. 按顺序执行 SQL 文件以完成实训
3. 部分操作需要实际的数据库环境（表、数据等）
4. 建议在学校提供的数据库环境中执行

## 注意事项

- 执行 DELETE、DROP 等危险操作前请备份数据
- 部分 SQL 语句需要根据实际表结构调整
- 存储过程和函数需要 MySQL 5.0+ 版本支持
- CHECK 约束需要 MySQL 8.0.16+ 版本支持
